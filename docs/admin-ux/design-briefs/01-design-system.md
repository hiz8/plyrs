# D1: デザインシステム

共通の土台(案 H)をキャンバス上で確定させる。読む設計書: [h-design-tokens.md](../h-design-tokens.md)、[h-common-surface.md](../h-common-surface.md)。進め方と共通の決まりは [README](./README.md)。

## 1. 作るもの

1. **プリミティブトークンの見本**: 色の尺度(white、gray、blue、red、green、amber の各段と `blackAlpha*`)、余白(`space0`〜`space9`)、文字(サイズ 6 段・太さ・行の高さ)、角丸、罫線、影
2. **セマンティックトークンの見本**: [h-design-tokens.md](../h-design-tokens.md) 3 章の各トークンを、ライトとダークで並べたもの
3. **共通部品**: 既存 7 種の見直しと、新規 15 種([h-common-surface.md](../h-common-surface.md) 3 章の表)。各部品の状態(通常・ホバー・フォーカス・押下・無効、該当するものはエラー)をライトとダークで描く
4. **ページの骨格の見本**: パンくず・見出し・主操作・補助操作・接続バナー・本文の並び([h-common-surface.md](../h-common-surface.md) 2 章)

## 2. ここで決めること

[h-design-tokens.md](../h-design-tokens.md) 6 章の未決事項のうち、見た目で決めるもの。

| 決めること                                  | 決め方の目安                                                               |
| ------------------------------------------- | -------------------------------------------------------------------------- |
| `gray300` / `gray500` / `gray800` の値      | 前後の段との明るさの間隔が揃うように補間し、罫線・補足文字に当てて確認する |
| `#0b1220`(ダークの主ボタンの文字)の位置づけ | blue の尺度に段を足すか、`blue950` に寄せるか。ダークの主ボタンで比べる    |
| 成功・警告・エラーの色と、その面の色        | バッジ・バナー・トーストに当てて、ライトとダークのコントラスト比を確認する |
| `bg.raised` のダークの値(`gray800` の案)    | メニューとモーダルが地の色から区別できるか                                 |
| 影 `shadow1` / `shadow2` の値               | ダークでも浮いて見えるか                                                   |
| 部品の高さ(ボタン・入力欄・表の行)          | 余白の尺度の組み合わせで表す                                               |

アイコンセットを使うかどうか([h-common-surface.md](../h-common-surface.md) 12 章)も、ここで決める。使う場合は候補を 1 つに絞り、サイドバー・バッジ・空状態に当てて確認する。

## 3. 部品ごとの注意

| 部品           | 注意                                                                                                          |
| -------------- | ------------------------------------------------------------------------------------------------------------- |
| ボタン         | 塗り(主操作)・枠線(補助操作)・危険(削除の実行)・テキストリンク(公開ボックスの「削除」)の 4 種                 |
| 確認ダイアログ | 実行ボタンは操作名(「削除する」)。危険な操作は危険色                                                          |
| トースト       | 成功・エラーの 2 種。エラーには「再試行」ボタンを置ける形にする(公開の失敗、[案 C](../c-publish-box.md) 4 章) |
| バッジ         | 公開状態(公開中 / 未反映の変更あり / 未公開)とステータス(4 種)。色だけで区別せず文字を必ず入れる              |
| 表             | 選択のチェックボックス、並べ替えの印、行にマウスを乗せたときの操作リンク([案 D](../d-content-list.md) 5 章)   |
| タブ           | 件数付き。0 件のタブを薄く表示する状態                                                                        |
| 進捗表示       | 「3 / 10 件」のような件数付きの形と、ファイルのアップロードの形                                               |
| 空状態         | 説明文と次の行動のボタン。アイコンを使う場合はその位置                                                        |
| スケルトン     | 表の行・カード・フォームの 3 形                                                                               |
| 相対時刻       | 「10 分前」とツールチップの日時                                                                               |

## 4. 確認する状態

- 全部品: ライト / ダーク、キーボードのフォーカス表示
- フォーム部品: エラーと補足文(フィールドの説明文、[案 E](../e-content-type-design.md) 2.1)
- バッジとバナー: 成功・警告・エラーのすべてでコントラスト比を確認する
