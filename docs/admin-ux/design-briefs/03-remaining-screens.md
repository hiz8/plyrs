# D3: 残りの画面

D2 の骨格の上に、ホーム(案 B)、型設計(案 E)、メディア(案 F)、設定とアカウント(案 G)を確定させる。4 画面は互いに独立のため、どの順で作ってもよい。読む設計書: [b-home.md](../b-home.md)、[e-content-type-design.md](../e-content-type-design.md)、[f-media-library.md](../f-media-library.md)、[g-settings-account.md](../g-settings-account.md)。

## 1. 作るもの

| 画面                    | 内容                                                                                    | 設計書                 |
| ----------------------- | --------------------------------------------------------------------------------------- | ---------------------- |
| ホーム                  | 新規追加、自分の下書き、確認待ち、最近の更新、モジュールのウィジェット                  | B 2 章                 |
| ホーム(はじめての利用)  | 型が 0 件のときの案内(管理者と、編集者・閲覧者)                                         | B 2.6                  |
| 設定 › コンテンツタイプ | 型の一覧(並べ替え、モジュールの型の区別)                                                | E 5.1                  |
| 型の作成・編集          | 基本情報、フィールドの一覧、フィールドの追加(種類の選択 → 表示名)、フィールドの詳細設定 | E 3〜5 章              |
| メディア                | グリッド / リスト、絞り込み、ドロップでのアップロード、詳細パネル                       | F 3・4 章              |
| メディア選択ダイアログ  | 編集画面から開く選択ダイアログ                                                          | F 5 章                 |
| 設定 › 一般             | サイト名、識別子、公開 API の URL                                                       | G 3 章                 |
| 設定 › メンバー         | 一覧、メンバーの追加ダイアログ、ロールの変更                                            | G 4 章                 |
| 設定 › モジュール       | 説明付きの一覧、有効化 / 無効化                                                         | G 5 章                 |
| アカウント設定          | メールアドレス、パスワードの変更、所属しているサイト、テーマの切り替え                  | G 6.2、H トークン 4 章 |

## 2. ここで決めること

- ホームの枠の配置(2 列か 1 列か)と、モジュールのウィジェットの大きさの決まり
- 型の作成で「種類を選ぶ」段階の見せ方(10 種の並べ方、「上級者向け」の JSON の区別)
- フィールドの詳細設定を開く場所(行の展開か、ダイアログか、右側のパネルか)
- 型の変更時の注意(E 5.3)を出す位置
- メディアのグリッドのサムネイルの大きさ、画像以外のファイルの表示、アップロード中の仮表示
- メディアの詳細パネルを開いたときのグリッドの幅
- メンバーの追加で未登録のメールアドレスだったときの表示と、サインアップ画面の URL のコピー

## 3. 確認する状態

| 画面           | 状態                                                                                                         |
| -------------- | ------------------------------------------------------------------------------------------------------------ |
| ホーム         | 管理者 / 閲覧者、読み込み中、自分の下書き 0 件、確認待ち 0 件、型 0 件(はじめての利用)                       |
| 型設計         | 新規作成、フィールド 0 件、ドラッグで並べ替え中、フィールドを削除するときの注意、API 名の入力エラー          |
| メディア       | 0 件、ドロップ中、アップロード中(一部失敗、20 MB 超え)、未使用で絞り込み、使用中のファイルの削除確認、閲覧者 |
| 選択ダイアログ | 1 件だけ / 複数、ダイアログ内でアップロードした直後                                                          |
| メンバー       | 自分が最後の管理者のとき、ロールを下げるときの案内(最大 15 分)、自分を外すときの確認                         |
| 共通           | ダーク、狭い画面                                                                                             |
