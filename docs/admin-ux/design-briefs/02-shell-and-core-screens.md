# D2: 骨格と主要 3 画面

D1 の部品を使って、骨格(案 A)と、利用頻度の高い 2 画面(案 C・案 D)を確定させる。ここで骨格が決まれば、D3 の画面は部品の組み合わせで作れる。読む設計書: [a-navigation.md](../a-navigation.md)、[c-publish-box.md](../c-publish-box.md)、[d-content-list.md](../d-content-list.md)。

## 1. 作るもの

| 画面                 | 内容                                                                     | 設計書     |
| -------------------- | ------------------------------------------------------------------------ | ---------- |
| シェル               | 3 段のサイドバー、本文上部(パンくず・見出し・主操作)、切断時の接続バナー | A 2〜5 章  |
| サイドバーのメニュー | サイト切替、アカウントメニュー                                           | A 3.1・3.3 |
| サイト選択           | 所属が複数のときのサイト選択画面                                         | A 8 章     |
| コンテンツの一覧     | タブ・絞り込み・検索・表・一括操作・ページ送り                           | D 2〜7 章  |
| 編集画面             | フォームと右側の公開ボックス、モジュールのパネル                         | C 2〜8 章  |
| 作成画面             | 編集画面と同じ形で、公開ボックスのボタンが「公開」「下書き保存」         | C 3・6 章  |

## 2. ここで決めること

- サイドバーの幅、3 段の区切り方、現在地のハイライトの形、型の子項目(一覧・新規追加)の字下げ
- 型が多いとき(10 件以上)と、サイト名が長いときの見え方
- 同期状態の表示(正常時の点と「同期済み」、切断時の警告色)
- 公開ボックスの 4 つの状態(C 3 章の表)でのボタンの並び。主ボタンが右、補助ボタンが左を基本とする
- 公開ボックスでの「未保存の変更があります」「未反映の変更があります」の出し分け
- 一覧の公開列の表示(「公開中 ● 未反映の変更あり」をどう 1 列に収めるか)と、行の操作リンクの出し方
- 一括操作の実行中の進捗と、一部が失敗したときの結果の表示
- 幅 960px 未満での、サイドバーを開く上部バー、公開ボックスの位置(フォームの後ろ)と画面下部に固定する主ボタン

## 3. 確認する状態

| 画面     | 状態                                                                                                                  |
| -------- | --------------------------------------------------------------------------------------------------------------------- |
| シェル   | 管理者 / 閲覧者(設定の有無)、型 0 件の案内(A 7 章、管理者と編集者で文言が違う)、切断中、狭い画面、ダーク              |
| 一覧     | 24 件(1 ページ目)、0 件(イベント)、検索して 0 件、3 件選択中、一括公開の実行中、一部失敗、閲覧者、狭い画面            |
| 編集画面 | C 3 章の 4 状態、未保存の変更あり、公開の失敗(保存は成功)、本文の競合ダイアログ、切断中で公開が無効、閲覧者、狭い画面 |
| 確認     | 削除の確認ダイアログ(公開中のものを削除する場合の文言)、公開の取り下げ、未保存のまま離れるときの確認                  |
