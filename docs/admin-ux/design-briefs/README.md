# デザイン依頼書

管理画面 UX 再構築の見た目を、Claude Design のキャンバス上で確定させるための依頼書。ローカルの Claude Code から `/design` を実行するときに、該当する依頼書を読ませて使う。全体の計画は [実装ロードマップ](../../superpowers/plans/2026-10-17-admin-ux-rebuild-roadmap.md) を参照。

## 1. 進め方

| 回  | 依頼書                                                         | 作るもの                                           |
| --- | -------------------------------------------------------------- | -------------------------------------------------- |
| D0  | 本書 2 章                                                      | 既存の部品を同期したデザインシステムのプロジェクト |
| D1  | [01-design-system.md](./01-design-system.md)                   | トークンの値、共通部品 15 種、ライト / ダーク      |
| D2  | [02-shell-and-core-screens.md](./02-shell-and-core-screens.md) | サイドバーと本文上部、編集画面と公開ボックス、一覧 |
| D3  | [03-remaining-screens.md](./03-remaining-screens.md)           | ホーム、型設計、メディア、設定とアカウント         |

- 1 回ごとに確定させてから次へ進む。D2 は D1 の部品だけで組み、D3 は D2 の骨格の上に組む。後の回で部品が足りなくなったら、画面側で独自に作らず D1 の部品に足す
- 各回の最初に、依頼書と対応する設計書(`docs/admin-ux/*.md`)をキャンバスの作業に渡す。設計書は「何を置くか」、依頼書は「何を描いて何を決めるか」を書いている

### 1.1 /design への渡し方の例

```
/design docs/admin-ux/design-briefs/01-design-system.md と
docs/admin-ux/h-design-tokens.md、h-common-surface.md を読んで、
1 章の「作るもの」をキャンバス上に作成してください。
```

## 2. D0: 既存の部品をキャンバスへ持ち込む

- `/design-sync` で `packages/ui` の現在の部品(Button / TextField / TextArea / Checkbox / CheckboxGroup / Select / RichTextEditor)と `tokens.stylex.ts` を、デザインシステムのプロジェクトへ同期する
- 目的は、キャンバス上の見た目を実装できる範囲に保つこと。既存の部品を土台にすると、react-aria-components で作れない見た目を描いてしまうのを防げる
- 同期は 1 部品ずつ差分で行われ、一括の置き換えにはならない。D1 で部品を作り直したあとに、もう一度同期してキャンバスとコードを揃える(V1 の完了時)

## 3. 全回に共通する決まり

### 3.1 文言

- 画面の言葉は [h-common-surface.md](../h-common-surface.md) 4 章の対応表に従う。「レコード」「アセット」「テナント」は画面に出さない
- ダミーの英文や「Lorem ipsum」は使わず、4 章のサンプルデータの日本語を入れる。日本語の文字幅で崩れる箇所を早く見つけるため

### 3.2 必ず描く状態

画面ごとに、正常な表示に加えて次の状態を描く。実装後に崩れやすいのはこれらの状態のため。

| 状態       | 内容                                                 |
| ---------- | ---------------------------------------------------- |
| 空         | 0 件のときの空状態と次の行動のボタン                 |
| 読み込み中 | 同期完了前のスケルトン                               |
| 切断中     | シェル上部の接続バナーと、無効になったボタン         |
| 権限       | 閲覧者で見たとき(ボタンが消える・読み取り専用になる) |
| エラー     | 操作の失敗のトースト、入力欄のエラー                 |
| 多い・長い | 100 件、長いタイトル、長いサイト名                   |
| ダーク     | ダークテーマ                                         |
| 狭い画面   | 幅 960px 未満(サイドバーを畳んだ状態)                |

全画面の全状態を描く必要はない。各依頼書の「確認する状態」に挙げた組み合わせを描く。

### 3.3 キャンバス上で値を決めるときの約束

- 色・余白・文字サイズは、[h-design-tokens.md](../h-design-tokens.md) のプリミティブトークンの尺度から選ぶ。尺度に無い値が必要になったら、画面に直接書かずに尺度へ段を足す
- 部品と画面はセマンティックトークンの名前で色を指定する(`text.muted` など)
- 文字のコントラスト比は本文 4.5:1 以上、大きい文字と部品の境界は 3:1 以上を確認する

## 4. サンプルデータ

全回で同じデータを使う。

- **サイト**: 「plyrs のお店」(識別子 `shop-example`)。切替の確認用に「株式会社サンプル 公式サイト リニューアル準備用」(長いサイト名)も所属しているものとする
- **利用者**: owner@example.com(管理者)、editor@example.com(編集者)、viewer@example.com(閲覧者)
- **コンテンツタイプ**: お知らせ(24 件)、ブログ(8 件)、イベント(0 件)
- **モジュール**: 予約(有効)。サイドバーに出す型は 予約 / 予約枠 / 予約リソース
- **お知らせの例**

  | タイトル                                                                                          | 公開                     | ステータス   | 更新       |
  | ------------------------------------------------------------------------------------------------- | ------------------------ | ------------ | ---------- |
  | 年末年始の営業について                                                                            | 公開中・未反映の変更あり | 下書き       | 10 分前    |
  | 秋のキャンペーン                                                                                  | 未公開                   | レビュー中   | 3 時間前   |
  | 10 月の定休日                                                                                     | 公開中                   | 公開準備完了 | 昨日       |
  | 【重要】システムメンテナンスに伴うオンライン予約サービスの一時停止について(11 月 3 日 2:00〜6:00) | 公開中                   | 下書き       | 3 日前     |
  | 夏季休業のお知らせ                                                                                | 公開中                   | アーカイブ   | 2026/08/01 |

- **お知らせのフィールド**: タイトル(テキスト 1 行・必須・タイトルに使う)、URL スラッグ、本文(リッチテキスト)、アイキャッチ(画像・ファイル)、公開日(日時)
- **メディア**: 画像 30 件、PDF 3 件、動画 1 件。うち未使用 4 件。例: `autumn-campaign.jpg`(1920 × 1080、1.2 MB、2 件で使用)
